# Musica D&D

Musica para la campana **El dragon del pico Agujahelada** en Owlbear Rodeo.

Los archivos se usan con la extension **Tracks**. Para obtener la URL de una
pista, tomar el enlace `raw`:

```
https://raw.githubusercontent.com/Juan-Exe/musica-dnd/main/NOMBRE.mp3
```

| Archivo | Titulo en Tracks | Tags |
|---|---|---|
| `01-la-comarca.mp3` | La Comarca | viaje, tranquilo, pueblo, phandalin |
