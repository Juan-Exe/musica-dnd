# Musica D&D

Musica para la campana **El dragon del pico Agujahelada** en Owlbear Rodeo.

Se usa con la extension **Tracks**. La URL de cualquier pista se arma asi:

```
https://raw.githubusercontent.com/Juan-Exe/musica-dnd/main/NOMBRE.mp3
```

Para cargarlas todas de una vez: menu de Tracks -> **Import csv** -> `tracks-musica.csv`
