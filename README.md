# Musica D&D

Musica para la campana **El dragon del pico Agujahelada** en Owlbear Rodeo.

Se usa con la extension **Tracks**. La URL de cualquier pista se arma asi:

```
https://raw.githubusercontent.com/Juan-Exe/musica-dnd/main/NOMBRE.mp3
```

## Pistas

| `02-bolson-cerrado.mp3` | Bolson Cerrado | taberna, pueblo, descanso | Howard Shore - Bag End |
| `03-volver-a-casa.mp3` | Volver a Casa | emotivo, final, descanso | L. Goransson - Let's Go Home |

## Nombres de archivo

Sin espacios ni tildes: los espacios se convierten en `%20` en la URL.
